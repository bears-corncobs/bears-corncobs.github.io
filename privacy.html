Privacy Policy

Application: hermes-mail-readonly. Last updated: October 2026.

hermes-mail-readonly is a private tool used only by its owner, with the owner's own Google account. This policy describes how Google user data is handled.

Data accessed

With the owner's consent, the app uses the Gmail read-only scope (https://www.googleapis.com/auth/gmail.readonly) to read message metadata (sender, subject, date, labels) and, when needed for classification, message content.

How data is used

  • Only to detect new messages, classify them, and notify the owner. Data is not used for advertising, profiling, or any other purpose.
  • Message content may be sent to a large language model service (Microsoft Azure OpenAI, under the owner's own account) solely to classify or summarize the message for the owner.
  • Notifications sent to the owner through a private messaging app contain the sender and subject and a short summary, not the full message body.

Storage

  • The OAuth refresh token and the list of already-processed message IDs are stored on the owner's own computer, with file permissions restricted to the owner.
  • Email content is not copied to any database or server operated by the developer and is not retained beyond the processing of each message.

Sharing

Google user data is not sold, shared with third parties, or transferred to anyone, except to the language model service described above, which is used only to provide the function the owner requested. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Human access

No person other than the owner reads the owner's email through this app.

Revoking access and deletion

The owner can revoke access at any time at https://myaccount.google.com/permissions, and delete the stored token file from the computer where the app runs.

Changes

This policy may be updated; the date above will change when it does.
